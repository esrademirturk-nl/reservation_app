# Waypad — web app

Travel bookings from every source in one place: trips, day plans, wallet, suggestions and a printed travel book.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Stack: React 19 · Vite · TypeScript · Tailwind CSS v4 · React Router · lucide-react.
Demo data lives in `src/data/demo.ts`; see `DESIGN-NOTES.md` for screen → route mapping and data decisions.
